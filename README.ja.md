# Pixauro

**ピクセルアートとスプライトアニメーションのためのデスクトップエディター。**

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語

白紙のキャンバスから描くことも、PNG を読み込んで編集可能なアニメーションフレームにすることもできます。描画、パレット編集、スプライトの切り出し、画像のピクセルアート化をひとつの作業画面で行えます。スクリプトから素材を処理するための CLI も用意しています。

現在は開発初期の段階です。プロジェクトのファイル形式や API は、互換性を保たずに変更する場合があります。エディターの UI は現在主に英語です。README は英語・中国語・日本語で提供しています。

## できること

- **描画と編集。** ブラシ、消しゴム、スポイト、自動選択、セル移動を使えます。元に戻す・やり直す操作に加え、編集履歴も確認できます。
- **パレットの管理。** プロジェクト全体で共有する RGBA 色の編集、PNG からの色抽出、パレットの PNG 出力に対応しています。パレットの色を変えると、その色を使っているピクセルにも反映されます。
- **フレームアニメーション。** ひとつのプロジェクトで複数のアニメーションを管理し、それぞれのフレームレートを設定できます。レイヤー、オニオンスキン、フレーム間でピクセルを共有するリンクセルに対応しています。
- **既存素材の加工。** PNG をフレームに切り分け、切り出し範囲やオフセットを調整し、解像度と色数を減らせます。背景除去の結果を確認してから読み込めるほか、切り出した元のピクセルをそのまま使うこともできます。
- **素材の書き出し。** 単一フレームを PNG に、アニメーションをスプライトシートと JSON に書き出せます。CLI ではループ再生する GIF プレビューも作成できます。
- **作業画面の調整。** パネルの移動とサイズ変更、ピクセルグリッドの表示切り替え、透明部分の背景を明るく・暗くする設定ができます。

ピクセルアート化はフレームごとに処理します。背景除去や切り出し位置の自動調整は、手作業での修正が必要になる場合があります。キャラクターを認識する機能ではなく、フレーム間の一貫性も保証しません。

## ソースから起動する

次のものを準備してください。

- Cargo を含む、現行の安定版 Rust ツールチェーン。
- Node.js と npm。フロントエンドの対応バージョンは `^20.19.0 || ^22.13.0 || >=24` です。
- アプリアイコンなどのバイナリ素材を取得するための Git LFS。
- 使用する OS に応じた [Tauri 2 のシステム依存関係](https://v2.tauri.app/start/prerequisites/)。

リポジトリをクローンした後、ルートディレクトリで実行します。

```sh
git lfs install --local
git lfs pull
npm --prefix editor ci
npm --prefix editor run desktop
```

`desktop` はフロントエンドの開発サーバーとネイティブアプリを同時に起動します。通常のブラウザーでフロントエンドを開くだけでは、ネイティブのファイル操作や編集コマンドは利用できません。

現在のプラットフォーム向けにデスクトップパッケージを作成するには、次を実行します。

```sh
npm --prefix editor run desktop:build
```

### 最初のプロジェクト

1. プロジェクトを作成し、キャンバスのサイズを指定します。
2. パレットから色を選んで描くか、PNG をキャンバスへドロップして読み込み画面を開きます。
3. タイムラインでフレームを追加します。スプライトシートの読み込みでは、各行がひとつのアニメーションになります。切り出し範囲と再生結果を確認してから読み込んでください。
4. プロジェクトを JSON で保存すると、レイヤー、アニメーション、パレット、編集履歴が残ります。画像やアニメーション素材の書き出しには **Export** メニューを使います。

## コマンドライン

CLI はエディターと同じ素材処理を使い、デスクトップアプリを起動せずに実行できます。以下の例はリポジトリのルートで実行してください。`input.png` と `sheet.png` は手元の画像に置き換えます。

画像を最大 64 × 64、RGB 最大 16 色でピクセルアート化します。

```sh
cargo run --locked --release -p pixauro_cli -- pixelate input.png -o output.png --size 64x64 --colors 16 --background none
```

2 行 4 列のシートを、各 4 フレームのアニメーション 2 本に分けます。切り出したピクセルをそのまま使い、スプライトシートと GIF プレビューを書き出します。

```sh
cargo run --locked --release -p pixauro_cli -- animate sheet.png -o output --rows 2 --columns 4 --size 64x64 --fps 10 --no-pixelate --background none --gif
```

`--no-pixelate` を使う場合は、切り出した画像が収まるキャンバスサイズを指定してください。

アニメーション名、個別のフレームレート、正確な切り出し範囲を指定する場合は、JSON 設定ファイルを使えます。

```sh
cargo run --locked --release -p pixauro_cli -- animate sheet.png -o output --config cli/examples/animation.json
cargo run --locked --release -p pixauro_cli -- --help
```

[ピクセルアート化](cli/examples/pixelate.json)、[グリッドによるアニメーション](cli/examples/animation.json)、[切り出し範囲とオフセットの指定](cli/examples/slices.json)の設定例があります。コマンドライン引数は設定ファイルより優先されます。`--save-config recipe.json` で最終的な設定を新しいファイルに保存できます。進捗と注意事項は stderr に、出力先のパスは stdout に出力します。

## ファイル形式

| 形式                        | 用途                                                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| プロジェクト JSON           | 編集可能な作品、パレット、レイヤー、アニメーション、編集履歴の保存。                                                |
| PNG                         | 画像の入力。フレーム、パレット、スプライトシートの出力。                                                            |
| スプライトシート PNG + JSON | フレームの矩形領域、アニメーション名、フレーム順序、FPS を含む素材出力。`pixauro-spritesheet` v1 形式を使用します。 |
| GIF                         | CLI の `--gif` オプションで出力するループアニメーションのプレビュー。                                               |

プロジェクト JSON とスプライトシート JSON は用途が異なります。編集を続ける場合は、プロジェクトファイルを保存しておいてください。スプライトシートのメタデータは Pixauro 独自の形式のため、他のツールで使うには変換が必要な場合があります。

## 開発への参加

作品データの管理と画像処理には Rust、デスクトップアプリの基盤には Tauri 2、UI には React と TypeScript を使っています。

| ディレクトリ            | 役割                                                     |
| ----------------------- | -------------------------------------------------------- |
| `engine/`               | 作品データ、編集履歴、画像の入出力、共通の素材処理。     |
| `editor/`               | React UI と、`src-tauri/` 内のデスクトップホスト。       |
| `cli/`                  | コマンドラインでのピクセルアート化とアニメーション出力。 |
| `pixelart-abstraction/` | 透明度に対応したピクセルアート化アルゴリズム。           |

変更前に [AGENTS.md](AGENTS.md) を、UI を変更する場合は [DESIGN.md](DESIGN.md) も確認してください。どちらも現在は中国語で記述されています。リポジトリのルートで次を実行します。

```sh
sh tools/check.sh
```

Rust のフォーマットと Clippy、生成された IPC バインディング、ESLint、Prettier、TypeScript、フロントエンドのビルドを確認します。自動テストは実行しません。動作はデスクトップアプリまたは CLI で手動確認してください。

不具合報告、小さな修正、ドキュメントの改善を歓迎します。不具合を報告する際は、OS、ビルドしたコミット、再現手順、可能であれば小さな入力ファイルを添えてください。大きな変更は、先に issue で範囲を相談してください。

## アルゴリズムについて

ピクセルアート化モジュールは、Gerstner らの _Pixelated Image Abstraction with Integrated User Constraints_ に基づく独立した実装に、透明度の処理を加えたものです。実装上の判断や論文との差異は[アルゴリズムの説明](pixelart-abstraction/docs/algorithm.md)を参照してください。独自の拡張部分は、論文の手法と同じ検証を受けたものではありません。

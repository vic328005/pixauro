# 算法对应关系与实现选择

本 crate 根据 Gerstner 等人的《Pixelated Image Abstraction with Integrated User Constraints》独立实现空间分区与调色板联合优化，并实现第 5 节的用户约束。它把输入区域分配、颜色数量和颜色位置放在同一个迭代过程中处理。

本文页码指用户提供的 `pixelated_image_abstraction-journal.pdf` 内印刷页码。该文件首页标注预印日期 **2012-08-28**；正式期刊版刊于 **2013 年，Computers & Graphics 37(5):333–347**，两者日期应区别使用。论文未给出所有数值参数，也存在少量公式和文字之间的不一致。本实现把这些地方明确列出，因此不承诺与作者原始程序或论文配图逐像素一致。

## 2. 初始化

对应论文 §4.1，第 5 页。

1. 将不透明 8 位 sRGB 输入转换成 Lab。
2. 在输入范围内规则排列 `N` 个超像素中心。输入像素中心使用整数坐标；每个网格槽位的初始位置在其覆盖范围中间。
3. 输入像素分给几何距离最近的规则中心。恰好相等时取较小的网格索引。
4. 初始逻辑颜色为 **M 个输入像素的 Lab 均值**。这里不使用区域均色的平均。
5. 输入颜色的总体协方差矩阵为 `Σ`，使用总体方差分母 `M`，初温为：

\[
T_0 = \max(T_f,\;1.1\cdot2\lambda_{\max}(\Sigma)).
\]

`max(T_f, ...)` 是处理单色、单像素和其他零方差输入的工程选择；否则原式可能给出零温度。需要增长颜色时，初始逻辑色内部表示为两个沿主轴正负扰动的子簇，各占一半概率质量。两个子簇的平均仍是原始初始颜色。

主轴由缩放后的 3×3 对称 Jacobi 特征分解获得。最大特征值重根时按坐标轴投影选取确定的轴，并规范化符号。零协方差选择 `[1, 0, 0]`。该约定解决重根及符号的不唯一性，不是论文额外给出的要求。

## 3. 一轮空间优化

对应式 (1)、§4.2，第 3、5–6 页。

### 3.1 使用调色板颜色分区

输入像素 `i` 分给使下式最小的超像素 `s`：

\[
d(i,s)=\|Lab_i-c_{a(s)}\|_2
 +m\sqrt{N/M}\,\|x_i-x_s\|_2.
\]

`a(s)` 是当前关联的逻辑调色板索引，默认 `m=45`。两项都是欧氏距离，不能把整个和或其中某项平方后当作同一个准则。平方模式选项只影响后面的式 (2)，不改变式 (1)。

关键点是：用于分区的颜色来自当前调色板。区域均色只用于后续统计和双边滤波，不能直接替代 `c_a(s)`。论文图 5 说明了这一耦合关系的意义。

### 3.2 精确 KD 树查询

本实现没有固定半径的 SLIC 局部搜索窗，也没有为了速度忽略候选超像素。`SpatialIndex` 每轮按中心坐标构造平衡 KD 树；每个节点同时保存位置包围盒和 Lab 包围盒。下界为：

\[
\operatorname{dist}(Lab_i,B_{Lab})
 +m\sqrt{N/M}\operatorname{dist}(x_i,B_{xy}).
\]

只有该下界无法改善当前最优解时才剪枝。相等距离按原始槽位索引决胜；节点的最小索引也参与相等情况下的剪枝判断。上一轮标签只提供初始上界，不限制可选候选。

因此查询实现的是本 crate 浮点度量下、全部中心中的精确最小值。树能减少通常情况下的候选计算，但最坏情况下单次查询仍可能访问全部 `N` 个中心。测试用独立暴力遍历核对结果。论文没有充分规定局部搜索窗；使用全部中心是这里明确采用的解释，结果可能与采用局部窗的复现程序不同。

### 3.3 区域均值和四邻居中心平滑

分区完成后，对每个非空区域重新计算原始颜色均值 `m_s` 与坐标均值。然后用**初始化时固定的输出网格四邻居**同时更新中心：

\[
x_s^{new}=(1-\eta)x_s+\eta
\frac{\sum_{t\in\mathcal N_4(s)}x_t}{|\mathcal N_4(s)|},
\qquad\eta=0.4.
\]

边缘只平均实际存在的邻居，单格保持原位。这是 Jacobi 同步更新，不读取已经更新过的邻居。平滑后的中心影响下一轮分区。

空槽位保留此前的均色与中心，再参加中心平滑。没有重要性地图时仍采用论文的均匀区域先验；有地图时空槽位权重为零。这个处理避免除零，但并不保证每个输出槽位都有非空、连通的输入区域。

### 3.4 在输出网格上做双边滤波

把 `m_s` 按输出格位置组成图像，得到：

\[
m'_s=\frac{\sum_t m_t
\exp(-\|u_s-u_t\|^2/(2\sigma_x^2))
\exp(-\|m_s-m_t\|^2/(2\sigma_c^2))}
{\sum_t
\exp(-\|u_s-u_t\|^2/(2\sigma_x^2))
\exp(-\|m_s-m_t\|^2/(2\sigma_c^2))}.
\]

这里的平方来自所选的高斯双边滤波核，与式 (2) 是否平方是两个独立问题。默认采用半径 2 的正方形核、`spatial_sigma=1`、`color_sigma=3`，边缘截断后重新归一化。半径 0 等价于保持均色不变。论文要求双边滤波，但未规定这些核参数。较小的颜色 σ 会降低不同颜色区域之间的混合，具体数值可以按图像内容和输出尺寸调整。

## 4. 调色板迭代与成对子簇

对应 §4.3、式 (2)–(4)，第 6–7 页。

### 4.1 概率关联

令 `A_s` 是区域 `s` 允许使用的逻辑颜色集合。内部簇 `j` 属于 `g(j)`，则默认概率为：

\[
q_{sj}=\frac{\mathbf1[g(j)\in A_s]\pi_j
\exp(-\|m'_s-c_j\|_2/T)}
{\sum_l\mathbf1[g(l)\in A_s]\pi_l
\exp(-\|m'_s-c_l\|_2/T)}.
\]

必须先用旧的 `π_j` 计算整张概率表，然后更新所有质量和中心。不能边计算一列边用其新质量影响其他列。

实现用 log-sum-exp 归一化。禁止项严格为零；空允许集合在 API 层拒绝。质量计算对数前使用 `max(π_j, 1e-300)`，使因先前约束而没有质量的颜色在新约束下能够重新获得样本。极小质量簇保持原有中心，避免除以接近零的数。这是有限精度和交互编辑的数值处理。

### 4.2 更新质量与中心

\[
\pi_j^{new}=\sum_s w_s q_{sj},
\qquad
c_j^{new}=\frac{\sum_s m'_s w_s q_{sj}}{\pi_j^{new}}.
\]

默认 `w_s=1/N`，不按区域面积加权。固定颜色仍更新概率质量，但跳过中心更新。

增长阶段，输出颜色为同对子簇中心的**算术平均**；对同对子簇的 `q_sj` 求和后，再选择概率最大的逻辑颜色。这是把对子簇概率边缘化为逻辑颜色概率的明确实现选择。论文说明了配对和平均颜色，但未完整规定逻辑硬关联的细节。

由于包含先验质量，最大概率颜色不一定是最近颜色。概率相等时选择较小逻辑索引。

### 4.3 检查收敛、降温与分裂

一轮的颜色变化量为内部簇中心位移的总和：

\[
\Delta=\sum_j\|c_j^{new}-c_j^{old}\|_2.
\]

当 `Δ <= palette_tolerance` 时，本温度下的调色板满足停止判据。如果尚未到最终温度，执行 `T = max(T_f, 0.7*T)`。还存在成对子簇时，随后进行一次 expansion：

1. 找出对子簇距离大于 `split_threshold` 的逻辑颜色。
2. 按距离从大到小选择可分裂项；距离相等时按原逻辑索引，最多使用剩余 `K` 个槽位。
3. 分裂时一个子簇保留原逻辑索引，另一个追加到末尾。未分裂的 pair 合为其算术平均，质量相加。
4. 未达到 K 时，每个逻辑色重新生成两个等质量子簇，并沿其后验加权协方差主轴作正负扰动。
5. 达到 K 后去掉冗余 pair，每个逻辑颜色只保留一个内部簇。

质量在拆分、合并过程中守恒。对子簇的重置与微扰发生于 expansion，不能每一轮 EM 都重置，否则会妨碍自然分离。论文 §3 的概述措辞与 §4.3 的详细步骤不完全一致，本实现采用后者。

在 `T_f` 上，如果已经没有可分裂项，就合并剩余 pair。合并后至少再完成一轮单簇表示的优化，达到同一停止判据后才返回 `Converged`。因此调色板可能少于 K 个颜色。饱和和 RGB 裁剪还可能使不同槽位显示为同一个 RGB 值；槽位不会因此重排或自动去重。

### 4.4 论文的距离与临界温度不一致

论文第 3 页声明距离默认使用欧氏距离，第 6 页式 (2) 的指数中确实没有平方。本实现默认忠实使用该范数。

不过，第 5 页的 `T_c=2*λ_max`，以及第 7 页的加权算术均值更新，与经典平方失真确定性退火理论相对应。直接把这些理论保证套到论文印出的非平方指数上并不成立。

`AnnealingDistance::SquaredEuclidean` 显式把式 (2) 改为 `exp(-distance²/T)`，其他步骤保持不变。它是可选择的算法变体，不是默认模式的隐式修正。即使选择平方形式，交替空间分区、硬颜色关联和双边平滑仍使整个过程不同于固定数据的单纯 DA 优化；本 crate 不承诺全局最优或所有输入必然收敛。

## 5. 用户约束与继续运行

对应 §5.1–§5.4，第 8–9 页。

### 5.1 重要性地图

输入权重 `W_i` 必须在 `[0,1]` 内、有限、长度为 M，并且至少有一个正值：

\[
w_s=\frac{\frac1{|p_s|}\sum_{i\in p_s}W_i}
{\sum_t\frac1{|p_t|}\sum_{i\in p_t}W_i}.
\]

是**区域平均重要性**再归一化，不是区域权重之和。区域大小不同也不能改成按总和加权。每次重分区后重新计算。

存入地图前先除以最大输入权重；式 (5) 对整体正数缩放不变，这样能支持很小的合法正数。全零地图的归一化无定义，返回 `InvalidImportance`；使用 `None` 恢复均匀先验。无效新地图不会覆盖原有地图。

地图可以在首次运行前设置，也可以在当前状态上修改。设置地图本身不会重新初始化已进行的退火；如果希望从头按新地图优化，应创建新 `Pixelator`。

### 5.2 像素与调色板约束

首次返回 `Converged` 后，调色板索引固定，才能编辑颜色与像素允许集合。预算用完或取消不会提前开放编辑。

| API | 行为 |
| --- | --- |
| `set_pixel_constraint(x, y, allowed)` | 只在给定逻辑颜色集合中关联；集合去重排序，单色集合为硬锁 |
| `clear_pixel_constraint(x, y)` | 恢复允许全部现有颜色 |
| `edit_palette_color(index, rgb, locked)` | 修改中心；`locked=false` 时后续仍可更新 |
| `sample_palette_color(index, x, y, locked)` | 采用该区域最近一次分区的原始均色 `m_s`，不采用 `m'_s` |
| `unlock_palette_color(index)` | 解除中心固定，恢复后续更新与输出饱和 |

固定的显式 RGB 编辑会绕过输出饱和，并在返回的调色板中保持输入字节值完全一致。固定采样颜色保持其原始 Lab 均色，输出做一次 RGB 转换。这个约定使“锁定颜色”有清楚的用户语义；论文没有明确说明手工 RGB 锁定与饱和后处理的交互。

### 5.3 状态、取消与终止语义

`Pixelator` 保留输入 Lab、分区、中心、调色板、概率质量和当前温度。首次收敛后的再次优化保留这些状态，在 `T_f` 上继续，并保持全部约束，不重新增色或重新退火。

| `StopReason` | 保证 |
| --- | --- |
| `Converged` | 在 `T_f` 上调色板位移满足当前容差；最终 pair 处理已完成 |
| `IterationLimit` | 本次预算用完；返回可预览结果并保留未完成状态，可再次 `run()` |
| `Cancelled` | 进度回调停止；已经完成本轮的降温、分裂等阶段转换，可继续运行 |

`Converged` 的定义是调色板停止判据，不表示所有输入标签都不再改变，也不表示找到了全局最优。即使颜色全部固定，空间分区也只能在所执行的迭代中调整。

进度回调中的温度和颜色数描述该轮实际优化时使用的值；回调触发前可能已为下一轮降温或增色。若同一轮既满足最终收敛又收到取消，报告 `Converged`。

预览输出会根据当前调色板重新计算显示用关联，但不会改写下一轮 SLIC 要读取的内部颜色关联。因此分段运行和取消恢复不会因为生成预览而改变优化轨迹。独立测试比较了 80 轮连续运行、每次 1 轮的分段运行，以及每 20 轮取消后恢复的完整状态。

## 6. 颜色转换与最终输出

所有统计在 `f64` Lab 上进行。输入按不透明 8 位 sRGB 解释，先使用分段 sRGB 传递函数线性化，再通过 XYZ 转入 Lab。

本实现选择 sRGB **D65** 白点：`x=0.3127, y=0.3290`，对应 `XYZ=[3127/3290, 1, 3583/3290]`。矩阵和传递函数参考 [W3C CSS Color 4 的颜色转换示例](https://www.w3.org/TR/css-color-4/#color-conversion-code)，但这里的 Lab 保持 D65，不执行 CSS `lab()` 所采用的 D50 色适应。论文只写 CIELAB，未给白点、矩阵精度或色适应约定。

论文 §4.4 的后处理为 `a,b *= saturation`，默认 `1.1`，L 不变。饱和只用于生成输出，不写回优化状态，避免多次 `run()` 累积放大。

转回 RGB 时，逐通道裁剪线性 RGB 到 `[0,1]`，编码并四舍五入到 8 位。不做感知色域映射、不做抖动。不同色域或透明图片应由调用方先转换、合成到所需的不透明 sRGB 输入；核心数据类型不携带 ICC、alpha 或方向元数据。

| `position_smoothing` | 0.4 | 论文 §4.2 |
| `cooling_rate` | 0.7 | 论文 §4.3 |
| `final_temperature` | 1.0 | 论文 §4.3 |
| `saturation` | 1.1 | 论文 §4.4；设 1 可关闭 |

| `palette_tolerance` | 1.0 | 论文未给数值；采用所有内部簇的 Lab 位移总和，平衡收敛时间与精度 |
| `split_threshold` | 1.0 | 论文未给数值；对子簇分离阈值 |
| `perturbation` | 0.5 | 论文未给幅度；主轴正负各移动 0.5 |
| 双边滤波 | 半径 2，空间 σ=1，颜色 σ=3 | 论文未给核参数；采用较小颜色 σ 以保留细节 |

| `parallel` | true | 开启 `parallel` feature 时按工作规模使用 Rayon |

温度、两个 σ、容差、分离阈值、扰动和紧致度限制在有限的 `[1e-12, 1e6]`；这避免指数除法溢出、σ 平方下溢等情况。空间平滑在 `[0,1]`、降温率在 `(0,1)`、饱和倍数在 `[0,10]`，双边半径最多 16。宽高必须正且不超过输入对应维度，颜色上限为 256。

### 固定颜色 σ=10 的容差敏感性实验

早期独立实验构造 `40×30` 平滑 RGB 渐变，输出 `10×8`、最多 8 色，固定双边半径 2、空间 σ=1、**颜色 σ=10**，其余未列出的参数采用本实现相同设置。在本次 x86-64 验证环境中，不同容差得到下表。最终默认颜色 σ 已选为 **3**，因此本表是固定 σ=10 的历史参数敏感性结果，不代表最终默认参数下的迭代数。

| `palette_tolerance` | 欧氏式 (2) | 平方距离变体 |
| --- | --- | --- |
| 0.01 | 1028 轮后在 `T_f` 收敛 | 2000 轮仍未收敛；T≈587.558、5 色 |
| 0.1 | 596 轮收敛 | 690 轮收敛 |
| 0.5 | 508 轮收敛 | 330 轮收敛 |
| 1.0 | 243 轮收敛 | 225 轮收敛 |
| 2.0 | 120 轮收敛 | 145 轮收敛 |

这些是上述指定样本及 σ=10 设置的实测迭代数，不是通用性能承诺。较小容差会改变降温时机及后续轨迹，不只是让同一结果多算几轮。该实验中，严格 `0.01` 的欧氏模式在 500 轮时仅进行到 T≈16.597、3 色；继续原会话能完成。最终默认的容差 `1.0` 与颜色 σ=3 也不能保证任何图片都在 500 轮内收敛。应用应检查 `stop_reason`，选择继续当前会话或使用当前预览。

## 8. 并行方式与性能边界

Rayon 并行覆盖规模足够大的 RGB 转换、输入像素分配与区域统计、双边滤波、逐区域概率关联和逐簇颜色更新。

像素统计使用至多 32 个固定分片，目标分片长度至少为 16384 个输入像素，最后一片可以更短。分片边界由输入大小决定，和线程数无关；每片独立写自己的区域累加器，最后按分片索引顺序合并。概率表按行独立写，调色板按内部簇独立更新，而每簇内部按样本索引顺序累加。

这种方式不需要 `DashMap` 或热点锁；数据都用稠密索引的 `Vec` 保存。串行模式保持同样的累加顺序，在同一构建与运行平台上可跨 Rayon 线程数重复得到一致状态。不承诺不同 CPU、编译器或数学库之间浮点结果逐位一致。

主要内存为输入 Lab 与标签 `O(M)`、网格与空间树 `O(N)`、概率表 `O(N*C)` 和区域统计分片 `O(S*N)`；`C` 是内部簇数量，增长阶段可达 `2*K`，`S<=32`。因此极大输出网格与大调色板组合仍需要较多内存。没有 GPU 路径，也没有假设增加线程一定加速；小图通过工作量阈值走串行路径。

## 9. 适用边界

- 实现的是论文第 4–5 节的像素抽象及约束，不包含后文海报化、视频扩展或作者 GUI。
- 输出是规则低分辨率索引图。算法不理解脸、物体或语义；重要性地图和用户约束是主动引导它的接口。
- 空区域和局部拓扑变化有明确处理，但不保证区域连通、拓扑保持或手工像素画的线条质量。
- 固定颜色、允许集合、初始化白点、双边核、精确全局中心搜索、概率质量下限及收敛容差都会影响实际结果。
- 概率在 `T_f=1` 时通常更集中，但数学上不一定严格为 0/1；最终显式选择最大概率颜色。
- `PixelArt` 保留 palette 槽位，可能有未使用或转换后重复的 RGB 条目。实际不同显示颜色数不超过请求上限。
